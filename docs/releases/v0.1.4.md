# UniversalKM 0.1.4

- **Экран поддержки на языке интерфейса:** раньше тексты показывались по-русски, даже если интерфейс на другом языке.
- **Имена устройств по умолчанию переводятся:** телефон или планшет без своего имени подписан на языке интерфейса (например, «Tablet» вместо «Планшет»). Имя, которое вы задали сами, не меняется.

Обновление ставится из приложения: «Обновления» в подвале панели.
