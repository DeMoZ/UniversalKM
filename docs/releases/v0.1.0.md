# UniversalKM 0.1.0

Первая версия: мышь и клавиатура Mac переходят на телефон или планшет, когда курсор упирается в выбранный край экрана. Устройство видит обычную Bluetooth‑клавиатуру и мышь — ею работает ChameleonUltra с прошивкой UniversalKM, подключённый к Mac по USB.

## Что умеет

- До трёх устройств одновременно (телефоны, планшеты); ввод уходит тому, к чьей зоне подвели курсор.
- Схема в панели, как в настройках мониторов: дисплеи в системной раскладке, устройства перетаскиваются к любому внешнему краю, зона передачи подсвечена. Поворот, скорость указателя для каждого устройства.
- Возврат на Mac горячей клавишей ⌃⌥⌘⎋, автоматически — при отключении устройства и при выходе.
- Chameleon по USB или по Bluetooth: если выдернуть USB, работа продолжается по Bluetooth; без связи с Mac Chameleon отключает устройства, ничего не залипает.
- Обновления из релизов GitHub прямо в приложении, кнопка «♥ Поддержать».

## Установка

1. Скачайте `UniversalKM-0.1.0.zip`, распакуйте и перенесите `UniversalKM.app` в «Программы». Приложение без сертификата разработчика: первый раз откройте его через правый клик → «Открыть».
2. Прошейте ChameleonUltra пакетом `chameleon-ultra-hid-dfu-app-0.1.0.zip`: `scripts/firmware-flash.sh chameleon-ultra-hid-dfu-app-0.1.0.zip` из репозитория (см. README). Откат — `scripts/firmware-flash.sh --official`.
3. Выдайте доступ «Универсальный доступ» и разрешите Bluetooth.
4. Сопрягите телефон или планшет с `ChameleonUltra` в настройках Bluetooth. Сам Mac с Chameleon не сопрягайте.

## Известные ограничения

- На iPhone курсор мыши не двигается даже с AssistiveTouch; клавиатура работает.
- Горячую клавишу пока нельзя изменить.
- Без сертификата разработчика macOS сбрасывает «Универсальный доступ» после каждого обновления — его нужно включить снова.
