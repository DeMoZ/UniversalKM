# UniversalKM 0.1.1

- Иконка приложения и свой значок в строке меню; в режиме «Устройство» значок показывает, на телефон или планшет идёт ввод.

Обновление ставится из приложения: «Обновления» в подвале панели. Без сертификата разработчика macOS после обновления сбрасывает «Универсальный доступ» — включите его снова в настройках.
