# UniversalKM 0.1.11

- **«Файлы…» у каждого устройства:** кнопка теперь в строке Android‑устройства, под переключателями «Клавиатура и мышь» и «Общий буфер обмена». Она видна, пока к устройству есть связь через adb (Wi‑Fi или кабель с отладкой по USB).
- **Переключатель «Wi‑Fi» у каждого Android‑устройства** вместо кнопки «Включить Wi‑Fi» в разделе «Подключения». Включение по кабелю с отладкой по USB переводит adb телефона на Wi‑Fi, как раньше кнопка; без кабеля приложение ищет телефон по сохранённому адресу и через «Отладку по Wi‑Fi». Выключение отключает телефон от Wi‑Fi, и приложение не подключает его снова, пока переключатель не включат. Выбор сохраняется.
- Раздел «Файлы и фото» остаётся для фото iPhone и появляется, пока iPhone подключён кабелем.

Обновление ставится из приложения: «Обновления» в подвале панели.
