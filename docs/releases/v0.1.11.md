# UniversalKM 0.1.11

- **«Файлы…» у каждого устройства:** кнопка теперь в строке Android‑устройства, под переключателями «Клавиатура и мышь» и «Общий буфер обмена». Она видна, пока к устройству есть связь через adb (Wi‑Fi или кабель с отладкой по USB).
- Раздел «Файлы и фото» остаётся для фото iPhone и появляется, пока iPhone подключён кабелем.

Обновление ставится из приложения: «Обновления» в подвале панели.
