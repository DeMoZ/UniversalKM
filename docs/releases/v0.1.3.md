# UniversalKM 0.1.3

- **Возврат на Mac движением мыши:** чтобы вернуть ввод с телефона или планшета, доведите курсор до края устройства, обращённого к Mac, и толкните дальше. Курсор Mac появится на той же высоте края. Переключатель «Возврат на Mac движением через край» есть у каждого устройства (по умолчанию включён); ⌃⌥⌘⎋ работает как раньше.
- **Курсор Mac не мешает:** пока вы управляете устройством, курсор Mac скрыт и стоит на месте — сразу видно, где идёт ввод.
- **Язык системы:** интерфейс теперь на языке системы — английский, русский, немецкий, французский, испанский, португальский (Бразилия), итальянский, китайский (упрощённый), японский, корейский. Отдельный язык для приложения: Системные настройки → Основные → Язык и регион → Приложения.

Обновление ставится из приложения: «Обновления» в подвале панели.
