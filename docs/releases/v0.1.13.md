# UniversalKM 0.1.13

- **Просмотр вживую из панели.** В секции «Камера движения» у каждого устройства теперь своя кнопка «Смотреть вживую…». Окно камеры для этого открывать не нужно.
- **Окна в Dock.** Пока открыто окно UniversalKM (камера, просмотр вживую, файлы, фото), приложение видно в Dock и в ⌘Tab, и к окну легко вернуться из другого приложения. ⌘W закрывает окно. Когда закрыто последнее окно, UniversalKM снова живёт только в строке меню.

Обновление ставится из приложения: «Обновления» в подвале панели.
