# UniversalKM 0.1.5

- **Android по кабелю, без Chameleon:** подключите телефон или планшет USB‑кабелем и нажмите «Добавить…» в панели. Mac становится для него обычной проводной клавиатурой и мышью (AOA2 HID). Отладка по USB не нужна, на телефон ничего не ставится.
- **Android по Wi‑Fi:** через `adb` (`brew install android-platform-tools`) и встроенную утилиту Android `hid`. Сопряжение по коду из «Отладки по Wi‑Fi» (Android 11+) или кнопка «Включить Wi‑Fi» для телефона на кабеле.
- **Кабель и Wi‑Fi вместе:** если выдернуть кабель, работа продолжается по Wi‑Fi, курсор остаётся на телефоне. Если телефон пропал из сети, ввод возвращается на Mac.
- **Телефон, воткнутый просто зарядиться, клавиатуру не получает,** пока вы не добавите его в панели.
- **ChameleonUltra теперь нужен для iPhone** (и для Android без режима разработчика). Если Chameleon в схеме не используется, панель не показывает ошибку «Chameleon не подключён».
- В панели у каждого устройства видно, как оно подключено: USB, Wi‑Fi или Bluetooth через Chameleon.

Обновление ставится из приложения: «Обновления» в подвале панели.
