# Proposal

## Why

У владельца есть Android-телефон и планшет, которые лежат рядом с Mac и подключены по `adb` (USB или Wi‑Fi). У Apple для iPad есть Sidecar: одна кнопка — и планшет становится вторым монитором. Для Android ничего подобного нет без платных приложений и сторонних драйверов, а у UniversalKM уже есть всё, на чём это строится: связь по `adb`, установка своих APK на устройство, ввод с Mac на Android. Это обратное направление к «Экран…» (add-android-screen-mirror): там экран телефона показывается на Mac, здесь Mac показывает свой рабочий стол на экране телефона.

## What Changes

- **«Использовать как монитор»** в меню устройства: одна кнопка создаёт на Mac виртуальный дисплей с пропорциями экрана телефона/планшета и показывает его на устройстве на весь экран. Он виден в «Мониторах» macOS как обычный второй дисплей: на него можно перетаскивать окна, расположение настраивается там же.
- **Приложение-приёмник** `ukm-display.apk` (отдельный маленький APK, без доступа к камере и файлам): декодирует видео и показывает его на весь экран, не даёт экрану погаснуть. Его ставит Mac по `adb install`, как приложение камеры движения; без кнопки оно ничего не делает.
- **Картинка:** Mac снимает виртуальный дисплей и отправляет на устройство H.264 по `adb` (USB или Wi‑Fi); цель — задержка до 80 мс по USB.
- **Касания** (этап 2): касание и перетаскивание на устройстве двигают курсор и нажимают мышью на этом мониторе; прокрутка двумя пальцами — колесо.
- **Поворот и закрытие** (этап 3): поворот устройства меняет режим виртуального дисплея; кнопка «Отключить монитор», отключение кабеля или закрытие приёмника убирают дисплей, а окна возвращаются на основной монитор.
- Этап 1 — прототип без касаний, чтобы замерить задержку до остальной работы; если она больше 120 мс по USB, изменение останавливается и пересматривается.

Вне этого изменения: звук Mac на устройстве, зеркальный режим (повторение основного монитора вместо расширения), перо/давление, несколько устройств-мониторов одновременно, iPhone/iPad, Windows и Linux как источник.

## Capabilities

### New Capabilities

- `android-second-display`: Android-устройство как дополнительный монитор Mac: виртуальный дисплей, картинка на устройстве, ввод касаниями, поворот, отключение.

### Modified Capabilities

(нет)

## Impact

- **Новый код:** `Sources/UniversalKMDisplay/` (маленькая ObjC/C-цель над приватным `CGVirtualDisplay`, SwiftPM не пускает приватные заголовки напрямую), `Sources/UniversalKMCore/SecondDisplay.swift` (формат потока, сообщения управления, пересчёт координат, выбор режима дисплея), `Sources/UniversalKM/SecondDisplaySession.swift` (дисплей, захват, кодирование, сокет), `android/display/` (приёмник), `scripts/build-display-apk.sh`, `Resources/ukm-display.apk`, тесты `SecondDisplayTests.swift`.
- **Изменения:** строка устройства в меню (кнопка), `build-app.sh` (копирует APK), `localization.py`, README (раздел и ограничения).
- **Права macOS:** «Запись экрана» (для захвата дисплея; приложению её ещё не запрашивали), «Универсальный доступ» уже требуется для ввода (нужен и для касаний).
- **Риск зависимости:** `CGVirtualDisplay` — приватный API Apple; для сборок вне Mac App Store допустим, но может измениться в новой macOS.
