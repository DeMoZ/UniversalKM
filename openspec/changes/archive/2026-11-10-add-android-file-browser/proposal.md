# Proposal

## Why

Чтобы взять фото с телефона или положить на него файл, сейчас нужен кабель и Android File Transfer или `adb push/pull` в Терминале. UniversalKM уже держит связь с телефоном через `adb`, по Wi‑Fi и по USB. По этой же связи можно показать память телефона в окне приложения и переносить файлы перетаскиванием в Finder и из Finder.

Сначала план был показать телефон прямо в Finder через File Provider. От этого отказались (2026‑11‑09): расширению File Provider нужна группа приложений с Team ID, а релизы подписаны самоподписанным сертификатом без Team ID. Для этого пришлось бы покупать Apple Developer ID. Своё окно работает и с нынешней подписью.

## What Changes

- **Кнопка «Файлы…»** в панели у выбранного Android-устройства, к которому сейчас есть связь через `adb` (по Wi‑Fi или по USB с отладкой). Кнопка открывает окно с памятью этого устройства. Для каждого устройства — своё окно; повторное нажатие поднимает уже открытое.
- **Окно файлов:** общая память (`/sdcard`: DCIM, Download, Documents…) списком с именем, размером и датой. Переход по папкам, «Назад», «Вверх», строка пути, обновление.
- **Перенос файлов:**
  - из окна в Finder перетаскиванием (файлы и папки скачиваются, пока Finder ждёт);
  - из Finder в окно перетаскиванием и «Вставить» (⌘V) после «Скопировать» в Finder;
  - кнопки «Скачать…» (выбрать папку на Mac) и «Отправить…» (выбрать файлы на Mac);
  - двойной щелчок по файлу — скачать во временную папку и открыть программой по умолчанию.
- **Правка на устройстве:** новая папка, переименование, удаление (с подтверждением, без корзины).
- **Ход переноса** внизу окна: имя, сколько готово, кнопка «Отменить». Обрыв не оставляет обрезанных файлов под настоящим именем ни на Mac, ни на телефоне.
- **Нет связи:** окно остаётся открытым и пишет «Устройство не подключено»; когда связь вернулась, список загружается сам.

Вне этого изменения: место в боковой панели Finder (File Provider), устройства только по USB в режиме AOA без отладки (там нет `adb`), Chameleon и iPhone/iPad, Quick Look в окне, синхронизация папок, доступ к файлам при закрытом приложении.

## Capabilities

### New Capabilities

- `android-file-browser`: окно с общей памятью Android-устройства через `adb`: когда оно доступно, что показывает, как переносить файлы между ним и Finder, какие правки на устройстве поддерживаются, что видит пользователь при обрыве связи и ошибках.

### Modified Capabilities

(нет)

## Impact

- **Новый код:**
  - `UniversalKMCore`: протокол хоста и sync `adb` (кодирование запросов, потоковый разбор `DENT`/`DNT2`, `DATA`, `DONE`, `FAIL`, `OKAY`), экранирование аргументов `shell`, модель списка папки (сортировка, путь) — с тестами;
  - приложение: клиент протокола поверх сокета `127.0.0.1:5037`, очередь переносов, окно файлов (SwiftUI + таблица на AppKit для перетаскивания в Finder).
- **Приложение:** `AndroidDeviceStatus` получает транспорт `adb` для файлов; кнопка в `MenuBarView.swift`; строки перевода на 10 языков.
- **Сборка и подпись:** без изменений. Песочницы нет, прав не добавляется.
- **Разрешения macOS:** новых запросов нет. `127.0.0.1` — не локальная сеть; с телефоном говорит сервер `adb` со своим разрешением (fix-adb-server-local-network).
- **Скорость:** по Wi‑Fi несколько МБ/с, иногда десятки; по USB с отладкой быстрее. Большие видео по Wi‑Fi копируются долго.
