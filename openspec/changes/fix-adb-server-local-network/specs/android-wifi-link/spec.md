# Spec Delta

## ADDED Requirements

### Requirement: Сервер adb после выхода из приложения
Сервер `adb`, который запустило приложение, SHALL сохранять доступ к телефонам по Wi‑Fi после выхода из приложения: при следующем запуске приложения и у `adb` в Терминале Android по Wi‑Fi SHALL работать без ручного перезапуска сервера. При выходе приложение SHALL NOT останавливать сервер `adb`. Если macOS спрашивает разрешение «Локальная сеть» для `adb`, README SHALL объяснять, что его нужно разрешить и где его включить потом.

#### Scenario: adb в Терминале после выхода
- **WHEN** приложение само запустило сервер `adb`, телефон подключён по Wi‑Fi, и пользователь вышел из приложения и выполнил в Терминале `adb connect <ip>:<port>`
- **THEN** подключение проходит, и телефон в `adb devices` в состоянии `device`

#### Scenario: Перезапуск приложения
- **WHEN** приложение само запустило сервер `adb`, и пользователь выходит из приложения и запускает его снова
- **THEN** телефон снова подключён по Wi‑Fi без действий пользователя

#### Scenario: Сервер пропал, пока приложение работает
- **WHEN** сервер `adb` остановили (например, `adb kill-server` в Терминале), а приложение работает
- **THEN** приложение поднимает новый сервер, телефон снова подключается по Wi‑Fi, и после выхода из приложения этот сервер тоже работает

#### Scenario: Чужие сессии при выходе
- **WHEN** в Терминале идёт `adb logcat` через тот же сервер, и пользователь выходит из приложения
- **THEN** `adb logcat` продолжает работать
