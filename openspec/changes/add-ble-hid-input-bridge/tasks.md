# Tasks

Работа идёт тремя шагами по просьбе пользователя. **После каждой группы (шага) — остановка: показать результат и ждать подтверждения пользователя.** Внутри шага 1 есть отдельная точка остановки: первая прошивка Chameleon (задача 1.9) — только с явного согласия пользователя. Группа 5 (обновления и донаты) добавлена по просьбе пользователя и выполняется сразу, до продолжения шага 1 с задачи 1.4. Задача 1.14 (несколько хостов) добавлена по просьбе пользователя после 1.9 и выполняется сразу после неё, до 1.10. Задача 1.15 (управление по Bluetooth и выключение HID без связи с Mac) добавлена по просьбе пользователя во время 1.12 и выполняется до завершения 1.12. Задача 1.16 (курсор на iOS) отложена пользователем и в шаг 1 не входит.
