# Spec Delta

## Purpose

Определяет, как пользователь может поддержать разработку UniversalKM: кнопка в панели и окно «Поддержать UniversalKM» со сведениями о приложении и способами доната. Ссылки и тексты загружаются из общего репозитория донатов, поэтому их можно менять без нового релиза.

## ADDED Requirements

### Requirement: Кнопка «Поддержать» в панели
В панели SHALL быть кнопка «♥ Поддержать». Она открывает окно «Поддержать UniversalKM». Время от времени кнопка SHALL привлекать внимание коротким эффектом (пульс, покачивание или розовое свечение), а остальное время оставаться неподвижной. При включённом «Уменьшении движения» SHALL использоваться только свечение.

#### Scenario: Открытие окна
- **WHEN** пользователь нажимает «♥ Поддержать» в панели
- **THEN** открывается окно «Поддержать UniversalKM» на переднем плане, а панель закрывается

#### Scenario: Уменьшение движения
- **WHEN** в настройках универсального доступа macOS включено «Уменьшение движения»
- **THEN** кнопка не пульсирует и не качается, а только иногда подсвечивается

### Requirement: Окно «Поддержать UniversalKM»
Окно SHALL показывать иконку, название и версию приложения, ссылку на github.com/DeMoZ/UniversalKM, текст-обращение и список способов доната. У каждого способа есть название, необязательное описание и кнопка «Поддержать…», которая открывает страницу оплаты в браузере. Окно SHALL служить и окном «О программе».

#### Scenario: Список способов
- **WHEN** файл донатов содержит способы Tribute и CloudTips
- **THEN** окно показывает оба способа в том же порядке, и «Поддержать…» открывает их страницы в браузере

### Requirement: Способы доната загружаются из репозитория донатов
При каждом открытии окна приложение SHALL загружать файл `universalkm.json` формата schema 1 из репозитория DeMoZ/donations: сначала с raw.githubusercontent.com, затем с зеркала jsDelivr. Удачную копию SHALL сохранять в кеш. Пока идёт загрузка или если она не удалась, SHALL показываться последняя сохранённая копия. Если копии нет — сообщение об ошибке и «Повторить».

#### Scenario: Нет интернета, есть кеш
- **WHEN** окно открывают без сети, а раньше файл уже загружался
- **THEN** окно показывает способы из последней сохранённой копии

#### Scenario: Нет интернета и кеша
- **WHEN** окно открывают без сети впервые
- **THEN** окно сообщает, что не удалось загрузить способы доната, и предлагает «Повторить»

### Requirement: Безопасные ссылки и разбор файла
Файл SHALL разбираться нестрого: неизвестные поля пропускаются, способ без названия или без ссылки `https://` отбрасывается. Файл без единого подходящего способа SHALL считаться недействительным и не перезаписывать кеш.

#### Scenario: Ссылка не https
- **WHEN** в файле есть способ со ссылкой `http://…` или `javascript:…`
- **THEN** этот способ не показывается, остальные показываются

### Requirement: Тексты на языке пользователя
Тексты файла SHALL выбираться по предпочитаемым языкам macOS: сначала точный тег языка, затем его базовый язык, затем английский.

#### Scenario: Русский интерфейс
- **WHEN** основной язык macOS — русский, а в файле есть тексты `en` и `ru`
- **THEN** окно показывает тексты `ru`

#### Scenario: Язык без перевода
- **WHEN** основной язык macOS — немецкий, а в файле есть только `en` и `ru`
- **THEN** окно показывает тексты `en`
