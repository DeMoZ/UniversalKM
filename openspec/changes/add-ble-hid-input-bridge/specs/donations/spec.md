# Spec Delta

## Purpose

Определяет, как пользователь может поддержать разработку UniversalKM: кнопка в подвале панели открывает в самой панели раздел со способами доната (как в LocalAIBar). Ссылки и тексты загружаются из общего репозитория донатов, поэтому их можно менять без нового релиза.

## ADDED Requirements

### Requirement: Кнопка «♥ Поддержать» в подвале панели
В подвале панели SHALL быть розовая кнопка «♥ Поддержать» рядом с «Обновления», версией приложения и «Выход». Нажатие SHALL показывать раздел «Поддержать UniversalKM» вместо основного содержимого панели, повторное нажатие — скрывать его. Отдельных окон для доната приложение не открывает.

#### Scenario: Открытие раздела
- **WHEN** пользователь нажимает «♥ Поддержать» в подвале панели
- **THEN** вместо основного содержимого панели появляется раздел «Поддержать UniversalKM», панель увеличивается по его содержимому и остаётся открытой

#### Scenario: Закрытие раздела
- **WHEN** раздел открыт, и пользователь нажимает крестик в его заголовке или снова «♥ Поддержать»
- **THEN** панель возвращается к основному содержимому и уменьшается

### Requirement: Раздел «Поддержать UniversalKM»
Раздел SHALL показывать заголовок с кнопкой закрытия, текст‑обращение и способы доната в порядке файла. Каждый способ — строка на розовом фоне с названием и необязательным описанием. Клик по строке SHALL открывать страницу оплаты в браузере.

#### Scenario: Список способов
- **WHEN** файл донатов содержит способы Tribute и CloudTips
- **THEN** раздел показывает обе строки в том же порядке, и клик по строке открывает её страницу оплаты в браузере

### Requirement: Способы доната загружаются из репозитория донатов
При каждом открытии раздела приложение SHALL загружать файл `universalkm.json` формата schema 1 из репозитория DeMoZ/donations: сначала с raw.githubusercontent.com, затем с зеркала jsDelivr. Удачную копию SHALL сохранять в кеш. Последняя сохранённая копия SHALL показываться сразу, а во время загрузки рядом с заголовком SHALL крутиться индикатор. Если копии нет и загрузка не удалась — текст «Не удалось загрузить способы поддержки. Проверьте интернет и откройте ещё раз.»

#### Scenario: Нет интернета, есть кеш
- **WHEN** раздел открывают без сети, а раньше файл уже загружался
- **THEN** раздел показывает способы из последней сохранённой копии

#### Scenario: Нет интернета и кеша
- **WHEN** раздел открывают без сети впервые
- **THEN** раздел сообщает, что способы поддержки загрузить не удалось, и советует проверить интернет и открыть раздел ещё раз

### Requirement: Безопасные ссылки и разбор файла
Файл SHALL разбираться нестрого: неизвестные поля пропускаются, способ без названия или без ссылки `https://` отбрасывается. Файл без единого подходящего способа SHALL считаться недействительным и не перезаписывать кеш.

#### Scenario: Ссылка не https
- **WHEN** в файле есть способ со ссылкой `http://…` или `javascript:…`
- **THEN** этот способ не показывается, остальные показываются

### Requirement: Тексты на языке пользователя
Тексты файла SHALL выбираться сначала для языка интерфейса приложения (сейчас русский), затем по предпочитаемым языкам macOS; для каждого языка — сначала точный тег, затем базовый язык, в конце — английский.

#### Scenario: Русский интерфейс при английской macOS
- **WHEN** интерфейс приложения русский, основной язык macOS — английский, а в файле есть тексты `en` и `ru`
- **THEN** окно показывает тексты `ru`

#### Scenario: Нет перевода на язык интерфейса
- **WHEN** у способа доната есть описание только на `en`
- **THEN** окно показывает описание на `en`
